# Original IDMap paper materials

This directory contains the original paper implementation and demo assets:
[`IDMap-MLP/`](IDMap-MLP/), [`IDMap-Diff/`](IDMap-Diff/),
[`SA-toolkit/`](SA-toolkit/), [`data/`](data/), and [`sample/`](sample/).
The paper's audio demonstration is available through [`index.html`](index.html).
Install this implementation's [`requirements.txt`](requirements.txt) in an
isolated environment. Its model files and entry points are distinct from the
Qwen3-TTS/CosyVoice3 pipeline described in the [repository README](../README.md).
The original paper figures remain at [`../figures/`](../figures/) so their
published links continue to work.
